# Taverna Bot

O taverna Bot é uma ferramenta para ajudar os narradores de RPG de mesa do servidor do discord _"Taverna Medieval"_ a gerenciarem suas campanhas e ferramentas específicas para o jogo como um todo.

## 1. O que é esse projeto?

Este projeto é um bot para o discord que facilita tarefas de gerenciamento de fichas de RPG dos narradores e oferece ferramentas específicas para o jogo como: Gravação de sessão, criação e edição de fichas (além de suas alterações ao longo do tempo para criar um histórico delas), gerenciamento de inventário, rolagem de dados, streaming de músicas do youtube e integração com a nossa cloud pessoal.

## 2. Tecnologias Utilizadas
- Typescript
- Nest.js
- discord.js
- node.js
- MongoDB
- Redis
- RabbitMQ
